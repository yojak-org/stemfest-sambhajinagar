STEM FEST load test

Run this two days before the event, after the content freeze, on the final data. It copies event-day traffic: many visitors opening the site and rating, while judges sign in and save scores and the organiser dashboard is open, all at the same time.

Before you start
  1. In the Judges tab, add a test judge: judge_id J99, name Load Test, PIN 9999, categories All.
  2. Set require_scan to FALSE and voting_open to TRUE for the test.
  3. Afterwards: STEM FEST > Clear all ratings and scores, delete the J99 row, and set require_scan back.
